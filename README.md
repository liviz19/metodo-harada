# 🧠 Método Harada

Una app ligera y visual para trabajar con el método Harada directamente desde el navegador.

Esta herramienta te ayuda a definir un objetivo, organizar tus áreas de trabajo y registrar acciones concretas con un seguimiento claro del progreso.

## ✨ ¿Qué incluye?

- Tablero visual con estructura tipo Harada
- Objetivo principal en el centro
- 8 áreas de trabajo
- 64 acciones organizadas por bloques
- Marcado de tareas como realizadas
- Guardado automático en el navegador
- Exportación a PDF tipo captura de pantalla
- Diseño responsivo y limpio

## 🧩 ¿Para qué sirve?

El método Harada ayuda a transformar un objetivo grande en pasos concretos y manejables. Esta app facilita ese proceso para que puedas:

- aclarar tu objetivo final
- desglosarlo en áreas
- definir acciones concretas
- seguir qué está hecho y qué falta
- guardar un avance visual del trabajo

## 🚀 Cómo usarlo

1. Abre la app en el navegador.
2. Escribe tu objetivo principal en el bloque central.
3. Rellena cada área con sus acciones.
4. Marca las tareas completadas con el círculo de cada casilla.
5. Revisa el progreso desde el contador superior.
6. Usa la opción de guardar copia para exportar el tablero a PDF.

## 📸 Exportación a PDF

La función de exportación está pensada para crear una captura limpia y útil de la vista actual, ideal para:

- guardar un avance del proyecto
- compartir tu plan con otra persona
- imprimir o archivar el tablero
- mantener un registro visual del progreso

## 💾 Guardado de datos

La app guarda automáticamente tu progreso en el almacenamiento local del navegador, así que no necesitas configurar bases de datos ni servidores.

## 🎯 Objetivo del proyecto

Crear una herramienta práctica, sencilla y visual para acompañar el método Harada sin depender de servicios externos ni herramientas complejas.

## 📝 Notas

- La aplicación funciona directamente en un navegador moderno.
- El exportado PDF se genera como una vista de la página actual.
- El diseño está pensado para ser claro, ligero y cómodo de usar.
